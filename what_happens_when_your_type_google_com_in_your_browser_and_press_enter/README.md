# What Happens When You Type Google.com in Your Browser and Press Enter

## Description

This project explains what happens behind the scenes when a user types `https://www.google.com` into a web browser and presses Enter.

It describes how different technologies work together to deliver a web page.

## Topics Covered

- DNS request
- TCP/IP
- Firewall
- HTTPS/SSL and TLS
- Load balancer
- Web server
- Application server
- Database
- HTTP response and browser rendering
